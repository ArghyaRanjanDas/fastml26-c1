## Goal
A student that carries pairwise (relational) information — the thing our DeepSet student lacks (float AUC 0.887, vs tt 0.759; teachers 0.915-0.925, vs tt 0.83-0.85) — and still fits the trigger budget: Xilinx VU9P `xcu200-fsgd2104-2-e`, 200 MHz, latency <= 1 us, ideally one SLR (~350k LUT, 700k FF, 1,900 DSP, 25 MB BRAM). Beat the DeepSet student: target float AUC >= 0.90 and HLS-closure AUC >= 0.895.

## Evidence this is possible
- arXiv:2510.24784 (Laatu et al., Oct 2025, "Sub-microsecond Transformers for Jet Tagging on FPGAs"): multi-head attention student over **16 particles, 1 head, no positional encoding**, trained with **HGQ** (per-parameter learned bit widths, EBOPs target ~350k) and implemented with **da4ml** distributed arithmetic: **98 ns latency, 279k LUT, 0 DSP** on an XCU250, II=1. That is our regime.
- hls4ml >= 1.2 supports MultiHeadAttention through the **HGQ2 frontend** (Keras 3), **Vitis backend, io_stream** (linear proj -> matmul -> LUT softmax -> proj). Plain Keras MHA is not converted; use HGQ2 layers.
- Fallback with evidence: interaction-network-style student = shared MLP over pairs (120 pairs of 16 candidates, pair features ln dR / m2 / kT from c2's study; ln dR is the useful one) then sum-pool; no softmax needed. c2 measured that the 6 "rich" per-candidate channels give +0.037 vs tt on the real 2k student, so include them as inputs when `team/data.py` exposes them.
